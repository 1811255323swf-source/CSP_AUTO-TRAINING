   AI 挂了退回 `data/questions.json`。

## 约定

- 出题来源由 `config.ini` 的 `app.provider` 决定；daily 任务必须带 `--allow-static-fallback`。
- `project_root` = 配置文件所在目录，所以 config.ini 必须放项目根，否则相对路径（data/、output/）会错。
- 未安装 `gh` CLI，无法远程触发 workflow，需呆呆在 GitHub 页面手动 Run workflow。
